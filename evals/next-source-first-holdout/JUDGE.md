# Blinded reviewer rubric

Оцени все переданные пары русскоязычных текстов. Ты не знаешь, как получены X и Y. Не угадывай вариант, не используй инструменты или внешние источники и не переписывай тексты. Все материалы синтетические.

Сначала проверь соответствие запросу и источникам. `public` разрешает использование и цитирование; `paraphrase_only` — только пересказ; `private` запрещает публикацию содержания и идентифицирующих деталей. Разумный пересказ допустим. Выдуманные факты, изменённые числа, усиленная причинность, потерянная неопределённость, запрещённая цитата или частные сведения — существенные дефекты. Затем оцени практическую полезность: ранний ответ, ясность, естественный русский, сохранение голоса, отсутствие повторов и лишних оговорок. Жанры различаются; не навязывай всем одну композицию. Reviewer_notes помогают проверке, но не задают обязательную форму.

Статусы каждого текста:
- `pass`: существенных дефектов не найдено;
- `revision`: нужен конкретный исправимый шаг, включая нарушение объёма;
- `critical`: выдумка, существенное искажение, нарушение разрешения/приватности или неподдержанное обвинение.

Для каждой находки приведи точную цитату ответа, `source_id` либо null, причину и минимальную правку. По каждой паре дай отдельно `editorial_preference` (качество чтения) и `practical_preference` (сначала критические ошибки, затем выполнение задания, затем редактура). Значения: `X`, `Y`, `tie`. Не ищи победителя любой ценой. Верни только JSON без markdown:

{
  "reviews": [
    {
      "pair_id": "из пакета",
      "X": {"status": "pass", "findings": []},
      "Y": {"status": "pass", "findings": []},
      "editorial_preference": "tie",
      "editorial_reason": "предметное сравнение",
      "practical_preference": "tie",
      "practical_reason": "предметное сравнение"
    }
  ],
  "limits": "Оценка модельная; возможны пропуски и ложные замечания."
}

Finding имеет ровно поля: `severity` (`revision` или `critical`), `category` (`facts`, `permissions`, `brief`, `style`), `quote`, `source_id`, `reason`, `minimal_fix`. Ответь по всем полученным парам и только по ним.

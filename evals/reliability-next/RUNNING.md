# Как проверить и повторить редакторскую регрессию

Это экспериментальный инструмент разработчика, не часть устанавливаемого навыка.
Команды запускают платные или учитываемые в лимитах модельные обращения только
с явным `--execute`. Не запускайте их в рабочем профиле агента. Все материалы
синтетические. Для нового опыта нужны новые каталоги назначения и свой бюджет:
результат модели не воспроизводится побайтово даже при тех же инструкциях.

Выполнять из корня этой версии репозитория с Python 3.10+ и доступным Codex CLI.
Для наблюдавшегося запуска отдельно проверена версия `codex-cli 0.153.4`;
полные параметры вызовов сохранены в manifest. Авторизуйтесь обычным способом,
не помещайте ключи в датасет, команды, отчёты или репозиторий.

## Только локальная техническая проверка

```bash
python3 -m unittest discover -s tests -v
python3 tools/validate_package.py
git diff --check
```

Эти тесты не вызывают модель и не удостоверяют достоверность текстов.

## Замораживание и 12 редакторских попыток

```bash
python3 tools/run_revision.py edit-prepare \
  --dest .local/editing-regression-2026-09-07-run \
  --dataset evals/reliability-next/regression.json \
  --protocol evals/reliability-next/PROTOCOL.md \
  --rubric evals/reliability-next/JUDGE.md \
  --editor evals/reliability-next/EDITOR.md

python3 tools/run_revision.py edit-run \
  --run-dir .local/editing-regression-2026-09-07-run --execute
```

`edit-prepare` не вызывает модель; существующий каталог не перезаписывает.
Ожидания и происхождение сохраняются в снимке, но не попадают в prompt.
`edit-run` создаёт новый ephemeral-контекст на каждый вызов, не загружает целиком
журналистский навык и не даёт редактору инструменты. Это проверка точного
[редакторского запроса](EDITOR.md), не нативной работы Hermes.

После первого вызова входы менять нельзя. Повтор команды не повторяет завершённые
попытки; незавершённая попытка блокирует продолжение. Не удаляйте attempt marker
ради повтора. Timeout, неполный ответ и нежелательное событие сохраняются как
сбой, а не как проверенный исходник.

## Слепое сравнение: до четырёх модельных рецензий

```bash
python3 tools/run_revision.py edit-blind \
  --run-dir .local/editing-regression-2026-09-07-run \
  --dest .local/editing-regression-2026-09-07-blind

python3 tools/review_ab.py prepare \
  --packet .local/editing-regression-2026-09-07-blind/packet.json \
  --rubric .local/editing-regression-2026-09-07-run/snapshots/judge.txt \
  --dest .local/editing-regression-2026-09-07-judges

python3 tools/review_ab.py run \
  --dest .local/editing-regression-2026-09-07-judges --execute
```

В исходной разметке оригинал занимает X шесть раз и Y шесть раз; seed `20260908`
задаёт только разметку, не генерацию. Второй судья получает обратный порядок
и переставленные X/Y. Два судьи не являются двумя человеческими редакторами.

## Экспорт без изменения ответов

```bash
python3 tools/run_revision.py edit-export \
  --run-dir .local/editing-regression-2026-09-07-run \
  --judges-dir .local/editing-regression-2026-09-07-judges \
  --dest evals/reliability-next/regression-results
```

Экспорт требует ровно 12 редакторских terminal records и attempt markers,
проверяет замороженную связь исходника и ответа, сырые события и запросы судьям.
Сохраняет точные тексты и отзывы, суммарные usage/время и все сбои. Исходные
черновики не считаются модельными вызовами. Неизвестные значения остаются
неизвестными, пропущенное ревью не становится `pass` или ничьей.

`quality_gate: not-adjudicated` намеренно не является автоматическим успехом.
Решение требует чтения окончательных текстов и разбора замечаний по источникам
по [заранее зафиксированному протоколу](PROTOCOL.md). Отчёт разработчика хранится
отдельно от неизменных модельных вердиктов. Сырые runtime-логи остаются в `.local/`;
не публикуйте их без отдельной проверки на личные данные и авторизацию.

Это известная разработчикам регрессия. Повтор на ней не заменяет новую приёмочную
выборку, человеческое чтение или проверку интеграции. Публикация на GitHub и
выбор лицензии — отдельные действия, ни одна команда выше их не выполняет.

# Как повторить сравнение

Этот эксперимент не запускается при установке навыка или в CI. Обычный
`python3 -m unittest discover -s tests -v` проверяет код на искусственных
ответах, без вызовов моделей. Такие unit-тесты не оценивают прозу.

Настоящее сравнение ниже делает **24 генерации и до 4 модельных рецензий**.
Оно расходует доступный лимит Codex. Нужны уже установленный и авторизованный
Codex CLI и Python 3.10+. Скрипты не получают и не копируют ключи, не покупают
кредиты, не меняют конфигурацию агентов и ничего не публикуют.

Запуск проверен с CLI 0.153.4. Варианты используют `gpt-5.6-sol`, рецензенты —
`gpt-5.6-sol` и `gpt-6-astra`, reasoning `medium`. Доступность этих идентификаторов
зависит от установки и аккаунта. В коде используются конкретные CLI-флаги,
включая экспериментальное отключение обнаружения навыков; это не обещание
совместимости со всеми версиями CLI.

Из корня репозитория:

```bash
# Подготовка без вызова модели: новый каталог, точные снимки и хеши.
python3 tools/run_ab.py prepare --dest .local/ab-my-run

# Осознанный запуск 24 ответов; каждый — новый контекст.
python3 tools/run_ab.py run --run-dir .local/ab-my-run --execute

# Пакет для проверки без названий вариантов и инструкций навыка.
python3 tools/run_ab.py blind --run-dir .local/ab-my-run --dest .local/ab-my-blind

# Подготовить рецензии по той версии рубрики, которая была заморожена.
python3 tools/review_ab.py prepare \
  --packet .local/ab-my-blind/packet.json \
  --rubric .local/ab-my-run/snapshots/judge.txt \
  --dest .local/ab-my-judges

# Осознанный запуск двух модельных рецензентов, по две партии каждому.
python3 tools/review_ab.py run --dest .local/ab-my-judges --execute

# Подготовить отдельный локальный экспорт для проверки перед публикацией.
python3 tools/summarize_ab.py \
  --run-dir .local/ab-my-run --judges-dir .local/ab-my-judges \
  --dest .local/ab-my-export
```

Подготовка требует нового каталога и не перезаписывает предыдущую попытку.
Продолжение `run` сохраняет уже завершённые попытки, включая неудачные.
При сбое не удаляйте запись ради красивого результата. Частичные файлы после
прерывания процесса требуют отдельного разбора, а не скрытой замены ответа.

Исходные JSONL-события и stderr оставляются в `.local/`: они могут содержать
служебные идентификаторы и локальные пути. Их нельзя автоматически отправлять
в публичный репозиторий. Для проверки читателю нужны синтетические вводные,
точные окончательные ответы, условия выполнения, измерения и отзывы, а не
внутренние журналы машины.

Перед использованием своего материала проверьте право передавать его выбранным
моделям. В опубликованном наборе все исходники вымышлены; отметка `private`
внутри задания моделирует редакционное ограничение, а не скрывает настоящие
чужие данные. Этот набор не разрешает экспорт реальных закрытых источников.

Сначала прочитайте [зафиксированный протокол](PROTOCOL.md) и
[рубрику рецензента](JUDGE.md). Даже успешно выполненный эксперимент не делает
его результат универсальным для других моделей, языков и типов текстов.

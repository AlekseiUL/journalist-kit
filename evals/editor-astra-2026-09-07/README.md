# Astra: шесть целевых ошибок исправлены

2026-09-07. **Регрессионный критерий пройден: 6/6 исправлений, шесть корректных
контролей без найденной существенной порчи.** Это известный набор, не доказательство
общей безошибочности, превосходства модели или готовности всего Journalist Kit.

Менялся только запрошенный редактор: Astra вместо Sol, medium, с тем же точным
[source-first EDITOR](../reliability-source-first-2026-09-07/EDITOR.md), COMMON и
исходными черновиками. Все 12 prompt hashes совпадают с прошлым опытом. Код получил
явный параметр модели с проверкой заморозки и совместимости, продукт beta.3 не менялся.

текущая практика/намерение и подмена позиции автора. e11 теперь сохраняет:

Также восстановлены обычные сроки изготовления и атрибуция части свидетельств.
Остались локальные места для улучшения — [аудит по источникам](AUDIT.md).

ненужным или считать его новым обязательным исправлением было бы неточно.

Совместных практических предпочтений редактуры шесть, четыре ничьи, два
разногласия. По чтению: ноль совместных побед, семь ничьих, пять разногласий.
**Улучшение живости не установлено.**

| Вариант | Sol: pass / revision / critical | Astra: pass / revision / critical |
|---|---:|---:|
| Исходник | 4 / 5 / 3 | 6 / 2 / 4 |
| Финал Astra | 12 / 0 / 0 | 12 / 0 / 0 |

Судейские pass не равны удостоверению истины. Разработчик и рабочий субагент
отдельно прочитали финалы и источники; субагент не читал новые отзывы. Это
неслепой модельный аудит, не человеческая приёмка. У судьи Astra и редактора
одна запрошенная модель; ошибки оценщиков не считаются независимыми.

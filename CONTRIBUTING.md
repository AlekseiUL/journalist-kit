# Как помочь улучшить Journalist Kit

Полезнее всего — воспроизводимая ошибка на конкретном тексте.

Приложите запрос, разрешённые исходники, получившийся текст, версию пакета,
модель и настройки, известные ограничения инструментов. Назовите ошибочную
фразу или решение и объясните, чем это подтверждается. Уберите личные данные,
закрытые документы, ключи и неразрешённые цитаты.

## Изменения

- Исправляйте подтверждённый дефект, не добавляйте запрет на нормальную грамматику.
- Для эвристики приложите пример срабатывания и похожий допустимый случай.
- Новая инструкция должна менять решение автора, а не повторять общие советы.
- Не добавляйте обязательного провайдера, сетевые вызовы или фоновую службу.
- Изменения голоса не должны распространять личную манеру одного автора на всех.
- Укажите происхождение стороннего кода/текста и совместимые условия использования.

## Проверка

```bash
python3 -m unittest discover -s tests -v
python3 tools/validate_package.py
git diff --check
```

Структурные тесты не доказывают качества прозы. Изменения редакторской методики
проверяйте на новом случае из [протокола оценки](docs/evaluation.md). Не изменяйте
рубрику задним числом, чтобы объявить удачным слабый результат.

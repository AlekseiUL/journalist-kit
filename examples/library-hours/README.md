# Часы библиотеки: точнее, без лишней тяжести

Это намеренно сконструированная учебная пара по вымышленным источникам. `before.txt` — текст с заранее внесёнными дефектами, а не ответ базовой модели. `after.txt` — пример допустимой редакторской версии, а не доказательство эффективности навыка или единственный эталон хорошего текста.

Задание: короткая новость для жителей с заголовком и точными часами работы в октябре. Исходные записи: [`sources.json`](sources.json).

## Что исправлено

- Сдвиг времени открытия и закрытия не назван увеличением рабочего дня.
- Указаны три конкретных дня и срок эксперимента; частное изменение не распространено на всю неделю.
- Убраны неподтверждённые удобство «для всех», рост посещений и постоянное расписание после октября.
- В цитату возвращена существенная граница «три дня в неделю».

После правки осталась обычная короткая новость с нужным читателю расписанием, без отчёта обо всех отвергнутых домыслах. Другие заголовки и композиции допустимы, если сохраняют факты, границы и полезность.

Чтобы проверить работу навыка самостоятельно, передай агенту задание и `sources.json`, не показывая `after.txt`. Сравнивай по [протоколу оценки](../../docs/evaluation.md), а не по буквальному совпадению с демонстрацией. Все даты и названия относятся к упражнению, не к актуальному сообщению.

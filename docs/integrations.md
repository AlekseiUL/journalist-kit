# Подключение к существующему агенту

Пакет — каталог `skills/source-and-voice/` в формате
[Agent Skills](https://agentskills.io/specification). Он не заменяет личность,
память, инструменты и правила разрешений вашего агента.

## Hermes

[Официальная инструкция Hermes](https://hermes-agent.nousresearch.com/docs/guides/work-with-skills)
описывает обнаружение `SKILL.md` и подгрузку вспомогательных файлов. Мы используем
обычный каталог навыка, а не production-плагин или новый gateway.

Из корня этого репозитория:

```bash
python3 tools/install.py --dest "$HOME/.hermes/skills"
python3 tools/install.py --dest "$HOME/.hermes/skills" --apply
```

Если автор работает в именованном профиле, выберите каталог этого профиля.
Пример для профиля с буквальным именем `writer`, **если он уже существует**:

```bash
python3 tools/install.py --dest "$HOME/.hermes/profiles/writer/skills"
python3 tools/install.py --dest "$HOME/.hermes/profiles/writer/skills" --apply
```

Установщик не создаёт и не выбирает профиль Hermes: он только копирует файлы
по указанному пути. Убедитесь в правильности пути на своей установке.
Иначе можно получить корректную копию, которую нужный агент не видит.

Начните новую сессию у выбранного агента. Попросите показать доступные навыки и
использовать `source-and-voice` для [короткого задания](../examples/post-request.md).
В интерактивной сессии Hermes навык можно загрузить командой
`/skill source-and-voice`; из CLI — флагом `hermes -s source-and-voice`.
Перезапуск сервиса, очистка истории и правка `SOUL.md` для копирования пакета не нужны.

Для проверки именно файлов, а не качества генерации:

```bash
python3 "$HOME/.hermes/skills/source-and-voice/scripts/editorial_check.py" \
  examples/library-hours/after.txt \
  --sources examples/library-hours/sources.json
```

Замените путь к скрипту для именованного профиля. Если Python/исполнение
недоступны хосту, инструкции остаются доступными, но агент обязан назвать
диагностику невыполненной; ручное чтение не становится запуском скрипта.

## Другие агентские системы

Укажите поддерживаемый вашим клиентом каталог навыков:

```bash
python3 tools/install.py --dest ./my-agent-skills
python3 tools/install.py --dest ./my-agent-skills --apply
```

Путь выше — пример локальной папки, а не универсальный каталог обнаружения.
Если клиент не поддерживает Agent Skills, подключите содержимое `SKILL.md`
в его инструкции и предоставьте доступ ко всем ссылочным файлам. Один скопированный
`SKILL.md` без references/scripts — неполный пакет.

Не добавляйте права на сеть, отправку или чтение личных файлов ради установки.
Не прописывайте фиктивный инструмент `editorial_check` в конфигурацию: пакет
предоставляет Python CLI, а вызов команд остаётся возможностью хоста.

## Обновление и удаление

Существующая установка никогда не перезаписывается автоматически. Перед
обновлением сохраните её резервную копию отдельно, сравните изменения, затем
установите новую версию в освобождённый каталог. Личные голосовые настройки
держите отдельно от файлов навыка.

Для отключения используйте управление навыками своего клиента либо переместите
только установленный каталог `source-and-voice` в резервную папку. Другие навыки,
профиль и история не относятся к этому пакету.

## Границы совместимости

Автотесты проверяют копирование, неизменность файлов и запуск установленного
скрипта из другой рабочей папки. Это не подтверждает автоматический вызов
проверок моделью и не заменяет проверку в выбранном клиенте/профиле.
Дополнительно локальная проверка на установленном Hermes 0.21.0 подтвердила
обнаружение навыка и чтение всех четырёх references в изолированном временном
home. Генерация в рабочем профиле не запускалась. Полный охват и ограничения —
в [отчёте выпуска](release-check.md).

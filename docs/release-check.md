## Исправления по независимому ревью

Два дефекта сначала воспроизведены падающими тестами, затем устранены:

1. Терминал с ASCII-кодировкой не мог вывести JSON с русским фрагментом или
   кириллическим путём. ASCII-safe JSON теперь сохраняет строки при декодировании
   без изменения исходных байтов, хеша и индексов.
2. На нечувствительной к регистру файловой системе путь к исходнику в другом
   регистре обходил защиту от вложенной установки. Проверка файловой идентичности
   существующих предков закрывает этот обход. На case-sensitive FS этот частный
   тест отмечается как skipped; на фактическом macOS-запуске он выполнен.

Также устранено расхождение схемы источников учебного примера и скрипта;
добавлен интеграционный тест публичной команды из README.

## Проверка обнаружения в Hermes

В установленном Hermes с metadata-версией `0.21.0` выполнена отдельная проба:
новый временный home, пустой рабочий каталог, минимальная среда, сеть запрещена.
Установлен только этот навык. Механизм обнаружения нашёл его ровно один раз;
`skill_view` прочитал `SKILL.md` и все четыре references с отключённым shell
preprocessing. Сетевых попыток не было.

Это проверка локального обнаружения и чтения на данной установке Hermes,
**не генерация в production-профиле**, не тест Telegram и не гарантия для каждой
версии Hermes. Рабочие профили не менялись, сервисы не перезапускались.

## Проба редакторского поведения

Четыре новых результата модельных субагентов сохранены вместе с заданиями:
[smoke-набор](../evals/smoke/README.md). Публичные файлы побайтно сверены с
первоначальными выходами, их объём повторно измерен. Основной модельный агент
отдельно перечитал источники и результаты.

При этом просмотре существенных искажений исходных фактов не обнаружено.
Два голоса различаются; разбор не превращает корреляцию в причину и сохраняет
знаменатели. Короткие посты всё ещё суховаты и повторяют часть оговорок.
Это не заявление о безусловном редакторском PASS для любых задач.

Контекст исполнителей — рабочие субагенты разработки, а не слепые чистые
запуски. Нет человеческой оценки, сравнения с baseline/конкурентом, повторов,
результата для всех шести режимов или проверки других моделей. Полная матрица
CI настроена, но на GitHub пока не запускалась.

## Перед публичным выпуском

После этого исторического отчёта владелец выбрал MIT License; одинаковый текст
лицензии находится в корне и в устанавливаемом навыке. Публичный выпуск этим
решением автоматически не выполняется. Перед отдельным выпуском нужно запустить
`python3 tools/validate_package.py --release`, повторить тесты, проверить
конкретный git diff и получить отдельное разрешение на внешнее действие.

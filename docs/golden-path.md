# Быстрый полезный маршрут

Journalist Kit полезнее всего не как «ещё один генератор статей», а как source-first редактор уже существующего автора.

## Обычный пост

Передайте черновик, цель и факты:

```text
Используй source-and-voice. Отредактируй этот черновик минимально: дай главную мысль раньше, убери повторы, сохрани мою позицию и не добавляй новых фактов. Верни только финальный текст.

Материалы: ...
Черновик: ...
```

Для такого задания не нужны анкета, полный source packet, отдельный агент или все references.
Перед ответом удалите каждую новую конкретную деталь, для которой нельзя указать точную опору в материалах.

## Ответственный материал

Передайте точный черновик и помеченные источники. Сначала получите финал, затем отдайте **ту же версию** отдельному рецензенту вместе с `templates/source-fidelity-review.md`.

```text
Проверь точный финал по исходному черновику и источникам. Ищи только существенное изменение субъекта, действия, времени, числа, условия, уверенности, позиции автора и прав цитирования. Для дефекта дай точную цитату и минимальную правку. Не переписывай всё.
```

После исправления перепроверь затронутые утверждения. Новый хеш или чистый checker не заменяет смысловую проверку.

## Когда остановиться

- Материал достаточен: вернуть текст.
- Опоры главной мысли нет: сузить вывод или запросить конкретный источник.
- Нужен контакт, поиск, публикация или закрытый материал: остановиться до реального разрешения хоста.
- Проверка не выполнена: не сообщать PASS.

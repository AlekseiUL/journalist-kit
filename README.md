# Journalist Kit

![Обложка Hermes Journalist Kit](assets/journalist-kit-cover.jpg)

Source-first редактура и журналистская работа для агента, который у вас уже есть.

[English](README.en.md) · [Быстрый маршрут](docs/golden-path.md) · [Пример](examples/library-hours/README.md) · [Установка](docs/integrations.md) · [Оценка](docs/evaluation.md)

Journalist Kit поставляет один переносимый навык `source-and-voice`. Он помогает
сохранять смысл источников, голос автора и заданную форму, а затем выполнять
один связный редакторский проход. Это инструкции для модели и отдельная
локальная диагностика, а не новый агент, модель или сервис.

## Что входит

- шесть результатов работы: угол материала, план интервью, карта фактов и
  пробелов, объяснение по источникам, статья и план расследования;
- шесть форм: новость, полезный разбор, интервью/профиль, репортажное
  повествование, анализ/колонка и журналистика решений;
- короткий маршрут для поста или минимальной редактуры;
- необязательный пользовательский профиль голоса;
- Python CLI `editorial_check.py`: точный UTF-8-хеш, объём, ограниченные
  стилевые сигналы и отдельные структурные риски использования источников;
- синтетические примеры, тесты и сохранённые экспериментальные оценки.

## Ограничения

Пакет не выполняет поиск, интервью, фактчек, модельную генерацию или публикацию.
Он не доказывает истинность, человеческое авторство, отсутствие редакторских
ошибок, превосходство над другими навыками или совместимость со всеми клиентами.
Диагностика всегда оставляет смысловую проверку источников в статусе
`NOT_REVIEWED`; exit code 0 не является допуском к публикации.

Опубликованные оценки выполнены на синтетических материалах. Рецензенты-модели
не являются людьми. Последний завершённый source-first holdout получил `HOLD`:
кандидат добавил неподдержанную сцену, получил 2/12 и 3/12 предпочтений двух
модельных рецензентов и увеличил input на 28,2% при лимите 15%.
[Точный аудит](evals/next-source-first-holdout/FINAL_AUDIT.md). Текущий
`0.2.0-alpha.2` — новый непроверенный кандидат, а не доказанное улучшение.

## Требования и чистая установка

Нужны Git, Python 3.10+ и агент с поддержкой каталогов навыков. У пакета нет
сторонних Python-зависимостей, сетевых запросов, телеметрии, ключей модели,
служб, MCP-сервера или автоматического изменения конфигурации.

```bash
git clone https://github.com/AlekseiUL/journalist-kit.git
cd journalist-kit
python3 tools/install.py --dest "$HOME/.hermes/skills"
python3 tools/install.py --dest "$HOME/.hermes/skills" --apply
```

Если репозиторий ещё закрыт, для клонирования нужны доступ и авторизация GitHub.
Первая команда показывает план, вторая копирует один новый каталог. Установщик
не выбирает профиль, не перезаписывает существующий `source-and-voice`, не
перезапускает сервисы и не меняет память, историю или конфигурацию. Для
именованного профиля укажите его фактический каталог `skills`; подробнее —
в [инструкции по подключению](docs/integrations.md).

## Проверка установки

Из корня репозитория установите пакет во временный каталог и запустите именно
установленную копию:

```bash
tmp="$(mktemp -d)"
python3 tools/install.py --dest "$tmp/skills"
python3 tools/install.py --dest "$tmp/skills" --apply
python3 "$tmp/skills/source-and-voice/scripts/editorial_check.py" \
  examples/library-hours/after.txt \
  --sources examples/library-hours/sources.json
```

Ожидаются `DRY_RUN`, затем `INSTALLED`, а в последнем JSON —
`source_review.status: NOT_REVIEWED`. Это проверяет файлы и запуск CLI, но не
качество текста и не обнаружение навыка конкретным агентом. Начните новую
сессию и явно попросите использовать `source-and-voice`.

## Короткие примеры

Редактура поста:

```text
Используй source-and-voice. Отредактируй черновик минимально: дай главную
мысль раньше, убери повторы, сохрани мою позицию и не добавляй новых фактов.
Материалы: ...
Черновик: ...
```

Материал по источникам:

```text
Используй source-and-voice. Подготовь sourced explainer по приложенным
источникам. Отдели установленное от неизвестного, сохрани оговорки и не
достраивай фон. Источники: ...
```

Для проверки локального файла доступны фактические флаги CLI:

```bash
python3 skills/source-and-voice/scripts/editorial_check.py BODY.txt \
  --sources SOURCES.json --voice VOICE.json \
  --min-words 100 --max-chars 3000
```

Полный контракт схем, лимитов и exit codes: [docs/checker.md](docs/checker.md).

## Если установка или проверка не прошла

Установщик возвращает JSON со статусом `ERROR` и exit code 2. Существующий
навык он не изменяет. Если ошибка возникла после создания нового каталога,
сообщение прямо просит осмотреть неполную новую копию; автоматического удаления
нет. Проверьте путь, права и отсутствие существующего `source-and-voice`, затем
используйте новый пустой каталог назначения.

CLI диагностики возвращает 1 для обнаруженной объективной блокирующей проблемы
и 2 для неверных аргументов, схемы, кодировки, размера или I/O. Не заменяйте
ошибку ручным утверждением о PASS.

## Безопасное обновление, удаление и откат

Установщик намеренно не обновляет поверх существующей копии. Сначала завершите
активную сессию, сохраните установленный каталог под новым именем вне каталога
обнаруживаемых навыков и установите новую версию в освободившийся путь. Не
храните личный профиль голоса внутри пакета.

Для отключения или удаления переместите только установленный каталог
`source-and-voice` в выбранную вами резервную папку. Для отката уберите новую
копию из каталога навыков и верните сохранённую на прежнее место. Не удаляйте
другие навыки, профиль или историю. После изменения начните новую сессию и
повторите проверку установленного CLI.

защитные ограничения. Они не оценивают литературное качество или фактическую
истинность. Воспроизводимые примеры должны использовать только разрешённые и
обезличенные материалы; см. [CONTRIBUTING.md](CONTRIBUTING.md).
